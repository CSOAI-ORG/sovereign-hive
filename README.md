## Overview

sovereign.meok.ai is a hive in the DEVELOPER cluster of the MEOK Empire. It provides AI-driven services, MCP endpoints, and agent infrastructure for its domain.

## MCP Servers

sso-mcp.sov3.meok.ai, agent-mcp.sov3.meok.ai, did-mcp.sov3.meok.ai

## Getting Started

1. Authenticate via OAuth 2.0 at `https://auth.sov3.meok.ai`
2. Obtain a bearer token with scopes: `agent:read`, `agent:write`, `mcp:invoke`
3. Invoke MCP endpoints at `https://mcp.sovereign.meok.ai/v1`
